# 心思维 AI 扒谱助手（XinsW Music Transcriber）

独立公开实验仓库，仅包含从原私有项目整理出的扒谱模块，不包含其他项目、用户音频或私人配置。

## Colab

Notebook：`notebooks/XinsW_Colab_Free_v2.ipynb`

当前流程处理已经分离好的人声主唱音轨，尝试提取主旋律并导出 MIDI、MusicXML 等结果；不负责从整首混音中自动分离人声。

首次运行需安装依赖并下载约 57.7 MB 的 CREPE full 模型。Colab 免费资源、GPU 可用性和运行速度不作保证。上传音频会传到 Google Colab 临时运行环境，请及时下载结果。导出 MIDI 不代表识别准确，需试听校对。
