# 心思维 AI 扒谱助手｜产品路线图（V1 / V2）

> 文档用途：作为每次继续开发前的统一交接依据。  
> 项目：XinsW Music Transcriber（心思维 AI 扒谱助手）  
> 当前版本规划基准：2026-11-24  
> 本文只记录已明确的产品决策、已知进展和待验证事项；不把计划写成已完成。

---

## 1. 产品目标

用户上传歌曲音频，系统分析真实音频中的音乐信息，提取旋律与节奏，生成可编辑、可校正的乐谱，并支持歌词排版。

目标输出包括：简谱、五线谱、MIDI、MusicXML、可预览和可打印的 SVG / PDF。

MusicXML 作为乐谱结构交换与后续排版的重要中间格式。音高识别、音乐事件、歌词编辑、MusicXML 生成和谱面排版应保持职责清晰，不能为了排版而篡改识别到的音高或节奏。

## 2. V1 与 V2 的明确边界

### V1：带歌词打谱（当前开发版本）

**核心原则：旋律由音频分析获得，歌词由用户输入。V1 不做自动语音转文字，也不做自动歌词识别。**

V1 工作流程：

1. 用户上传歌曲音频。
2. 按既定流程进行人声与伴奏分离；分离结果需要保留来源信息和质量说明。
3. 从人声主唱音轨提取主旋律音高与节奏，形成结构化音符 / Music Event 数据。
4. 用户手动输入或粘贴歌词。
5. 用户逐字检查、编辑歌词与音符的对应关系；支持逐音编辑、拖腔延续标记“—”、空歌词位置和休止处理。
6. 用户校正后保存歌词对齐结果。
7. 使用同一份结构化数据重新生成 MusicXML、简谱 SVG / PDF、五线谱 SVG 等输出。

V1 功能范围：

- 音频上传及任务处理；
- 人声 / 伴奏分离流程；
- 人声主旋律音高识别；
- 音符起止时间、节奏与休止信息处理；
- 自动定调分析（识别原曲调性，不改变原始音高）；
- 用户手动输入歌词；
- 歌词逐音编辑、对齐和人工校正；
- 拖腔延续“—”及空歌词处理；
- 保存歌词对齐记录；
- 根据修正后的数据重新生成 MusicXML；
- 简谱、五线谱预览及 SVG / PDF 等输出；
- MIDI 等结构化结果导出。

**V1 明确不包含：**

- 自动语音识别（ASR）；
- 自动歌词识别 / 自动听写歌词；
- 自动把音频中的人声转换成文字；
- 将 V2 的自动歌词识别服务作为 V1 的必要依赖。

### V2：自动歌词识别与辅助对齐

V2 在 V1 稳定基础上增加：

- 从音频自动识别歌词文本；
- 自动把歌词初步对应到旋律音符；
- 对重复段落、衬词、多音节词、拖腔延音等情况提供更好的自动处理；
- 保留人工检查、修改和确认能力。

V2 的自动识别结果不能被视为绝对正确；复杂段落仍需允许用户校正。

## 3. 伴奏识别的产品约束

- 伴奏必须以真实伴奏音频为依据进行分析。
- **不能根据人声主旋律凭空编造钢琴伴奏。**
- 若生成钢琴伴奏谱，必须能追溯到伴奏音轨中实际识别出的音符 / 声部信息。
- 应保留伴奏音频及其处理来源，区分真实识别结果、算法推断结果和人工编辑结果。
- 伴奏和弦、低音分析与完整钢琴多音符（左右手）转录的准确度和实现范围需要单独验证；在没有通过真实音频测试前，不得宣传为已完整支持。

## 4. 音频质量与模型评估原则

- 人声分离音轨可能残留混响、合唱或伴奏，不能默认是干净独唱。
- 每次模型评估必须记录输入音频来源、分离方式及音频质量。
- 不能仅凭 MIDI 文件成功生成，就认定旋律识别准确。
- 必须结合真实歌曲检查音高、八度、节奏、休止、乐句边界和调性。
- 合成音、人工构造样本与真实歌曲样本应分别标注，不能混为真实准确率。
- 自动定调只判断原曲调性；主动移调是另一项操作。调性分析不得擅自改变识别音高。

## 12. 2026-11-25 逐音歌词编辑首版实现状态

本轮按“先完成歌词逐音编辑，再完成自动 GPU 调度”的优先级开始实现。当前已加入首版代码，但尚未通过可见 CI / 本地真实运行验收，因此路线图状态为**已实现首版、待测试与体验验收**，不标记为完成。

- MusicXML 逐音槽位提取：每个有 pitch 的音符一个槽位；休止符不占槽位；tie continuation 不重复占槽位；返回 note index、音高和现有歌词。
- 编辑语义：每个音符槽位独立保存；空字符串代表清空该音的歌词；“—”保留为显式拖腔标记；歌词槽位数量必须与 MusicXML 实际槽位完全一致。
- 初步输入 tokenizer：将“— / –”识别为独立歌词单位，不再错误地附着到前一个汉字。
- 本地 API：`POST /api/job/{job_id}/lyrics`；只允许成功完成的本地 transcribe job；限制最多 1000 个槽位、单槽位最多 80 字符；写回 MusicXML、lyrics.txt、lyrics_alignment.json，并尝试重新生成五线谱 SVG、简谱 SVG/PDF。
